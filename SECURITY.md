# Security Policy

## Supported versions

`@zerovoids/http-core` is pre-1.0 (0.x). Security fixes are released for the latest
published minor only.

| Version | Supported |
| ------- | --------- |
| 0.3.x   | ✅        |
| < 0.3   | ❌        |

## Reporting a vulnerability

Please report vulnerabilities **privately** via GitHub's
[**Report a vulnerability**](https://github.com/gio-hernandez-saito/zerovoids-http/security/advisories/new)
(the repository's Security → Advisories tab). Do **not** open a public issue for a
security report.

You can expect an initial response within a few days. Once a fix is ready, a patched
version is published to npm and the advisory is disclosed.
